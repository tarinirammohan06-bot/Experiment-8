Experiment 08: Session Tracking

📌 Project Description

This project demonstrates Session Tracking in Django using sessions and cookies. Session tracking helps web applications maintain user-specific information across multiple requests.

The project includes two implementations:

* Session Tracking: Stores user-related information on the server using Django sessions.
* Cookie Tracking: Uses browser cookies to store and retrieve information across requests.

🎯 Objective

To understand and implement session tracking and cookie management in a Django web application.

🛠️ Technologies Used

* Django
* HTML
* Web Browser

⚙️ Installation and Execution

1. Install Python on your system.
2. Open the project folder in your terminal.
3. Install the required dependencies:

pip install -r requirements.txt

4. Run the appropriate Python application:

python app_session.py

    Or run the cookie application:

python app_cookies.py

5. Open the local URL displayed in the terminal in your web browser.

✅ Expected Output

* Shows how information can be maintained across multiple web requests.
